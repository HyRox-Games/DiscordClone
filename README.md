# DiscordClone (Safe & Authorized)

> هذا المشروع **لا يدعم** نسخ/استنساخ أي سيرفر بدون تفويض.  
> تم تنفيذ بوت Discord.js v14 لعمل **ترحيل هيكل السيرفر بشكل قانوني** (Roles + Channels + Categories) بعد التحقق من الصلاحيات.

## المزايا
- Slash Command: `/clone-server`
- التحقق أن المستخدم المنفذ Admin داخل سيرفر الوجهة.
- التحقق من صلاحيات البوت في المصدر والوجهة قبل أي عملية.
- خيار حذف القنوات/الرتب القديمة في سيرفر الوجهة قبل النسخ.
- نسخ هيكل السيرفر فقط (بدون رسائل/أعضاء/بيانات خاصة).

## المتطلبات
- Node.js `>= 18.18`
- Bot Token + Client ID
- مكتبات:
  - `discord.js@14`
  - `dotenv`
  - `chalk`

## الإعداد
1. ثبّت الحزم:
   ```bash
   npm install
   ```
2. أنشئ ملف `.env`:
   ```env
   DISCORD_TOKEN=your_bot_token
   DISCORD_CLIENT_ID=your_app_client_id
   ```
3. شغّل البوت:
   ```bash
   npm start
   ```

## الاستخدام
داخل سيرفر الوجهة نفّذ:

```txt
/clone-server source_guild_id:<SOURCE_ID> delete_existing:true|false
```

> يجب أن يكون البوت موجودًا في السيرفر المصدر والوجهة مع الصلاحيات المناسبة.

## ملاحظات أمنية
- أي محاولة نسخ بدون إذن صريح من مالك السيرفر مخالفة للشروط والقوانين.
- هذا الكود مصمم للاستخدام الإداري المصرح فقط.
